# AdalatIQ Legal Intake Frontend

Frontend application for the AdalatIQ Internship Screening Assignment.

## Features

* Legal consultation submission form
* Form validation using React Hook Form
* Responsive UI using Tailwind CSS
* Dashboard to view all legal submissions
* Search functionality for filtering submissions
* AI-generated category and priority badges
* Navigation between pages
* Loading states and error handling
* Deployed on Vercel

## Tech Stack

* React
* Vite
* Tailwind CSS
* Axios
* React Router DOM
* React Hook Form

## Pages

### Home Page

Users can:

* Enter name
* Enter email/phone
* Submit legal queries

### Dashboard Page

Displays:

* User name
* Contact details
* Legal query
* AI-generated category
* AI-generated priority
* Timestamp

Includes:

* Search functionality
* Responsive card layout

## Deployment

Frontend deployed on Vercel.

Live URL:

```bash

npm run dev
```
